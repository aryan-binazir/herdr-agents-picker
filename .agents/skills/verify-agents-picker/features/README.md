# Feature map

The executable boundary is the release TUI driven by keys in private tmux. Herdr CLI responses come from an owned fixture. Read [SKILL.md](../SKILL.md) for isolation, commands, and evidence.

- [Search](search.md): filtering, empty results, clearing, cancellation.
- [Navigation](navigation.md): selection and Enter focus.
- [Numbers](numbers.md): visible labels and direct dispatch, modifiers, search digits, scrolling, resize, reorder, and status icons.
- [Refresh](refresh.md): manual and automatic list updates.
- [Launch](launch.md): closing and `--open` requests.

Alpha and Beta are the normal fixture, initially idle in Verify / Checks. Numbers uses fourteen distinct threads and terminal titles, with smaller and empty fixtures where needed. Tests never read transcripts. Real popup geometry and real server focus require the separate private-Herdr driver; CLI fixture success does not prove them.
